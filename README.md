
# Simple Interest Calculator

## Project Description

This project is a Simple Interest Calculator created for the
IBM Introduction to Git and GitHub final assignment.

The calculator is implemented using a Bash script named
simple-interest.sh.

## Input

The calculator accepts three inputs:

- p: Principal amount
- t: Time period in years
- r: Annual rate of interest

## Output

The calculator displays the calculated simple interest.

## Formula

Simple Interest = (p * t * r) / 100

## How to Run

Run the following command in a Bash terminal:

```bash
bash simple-interest.sh
```

## Example

Principal: 1000
Rate: 5
Time: 2

Simple Interest: 100
